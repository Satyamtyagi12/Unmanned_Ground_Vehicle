
# 🚜 Unmanned Ground Vehicle (UGV)


## 📖 Overview

The Disaster Management UGV is designed to assist first responders during natural disasters and emergencies. Equipped with sensors, computer vision, and autonomous navigation, it detects humans, avoids obstacles, and stores critical data — enhancing the speed and effectiveness of rescue operations.


## ✨ Features

- Autonomous Navigation :- Uses ultrasonic sensors for real-time obstacle detection and adaptive path planning.
- Human Detection :- Employs computer vision techniques (YOLOv5) for accurate, real-time identification of humans.

- Obstacle Avoidance :- Dynamically adjusts its route to avoid collisions with objects and navigate complex terrains.

- Database Integration :- Captures GPS coordinates during human detection, converting them into readable locations using the Geopy library.

- Distance Measurement :- Measures the distance to detected humans via onboard camera, aiding strategic rescue planning.

## 🛠️ Hardware Requirements

- Raspberry Pi 4
- HCSR04 Ultrasonic Sensor
- Neo 6M GPS Module
- L298N Motor Driver
- DC Motors
- Mecanum Wheels
- 12V/3.5A Battery
- Camera
- 64GB Memory Card + Reader

## Features

- Raspberry Pi Imager
- Raspberry Pi OS (64-bit)
- Python 3.11
- PuTTY (SSH Client)
- IP Scanner
